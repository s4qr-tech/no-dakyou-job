# no-dakyou-job（自分軸ファインダー）

就活・インターン応募の前段として、幼少期から現在までを対話で深掘りし、妥協で狭まった選社軸をほどいて「本来の自分軸」を言語化する Claude スキル。そこから、プロフィール（ストーリー）と業界別の活かし方を作り、`/jobh-jp`（企業研究・募集評価・設問回答・面接準備）へ引き渡す。選考中は、会話で軸に照らした振り返りを続ける。

診断・カウンセリング・適性判定ではありません。「整理と言語化の支援」です。

## できること
1. 人生年表：幼少期〜現在の夢・熱中・転機を時系列に整理
2. 妥協の棚卸し：いつ・何を理由に・何を諦めたかを整理し、本当に欲しかったものを探る
3. 動機・価値観の抽出：感情が動いた場面から、大切にしたいことと強みを掘る
4. 自分軸の言語化：軸3〜5本と、根拠エピソード
5. ストーリー化：400字／800字（英語モードは英文も）
6. 業界別の活かし方：関心のある業界ごとに、軸が満たせる点・満たせない点・向く職種を整理
7. 伴走（会話のみ）：選考結果や違和感を話すたびに、軸に照らして振り返り、軸を更新

成果物は HTML（デザイナーが編集しやすい形）で出力します。希望すれば pptx / docx でも出力します。

## 3つの始め方

**1. URLを貼るだけ（claude.ai のチャット。Webアクセスが使える環境）**
次のメッセージをそのまま送る。スキルとして登録されるわけではなく、毎回URLから読み込んで動く。
```
https://github.com/s4qr-tech/no-dakyou-job の START.md を読んで、その手順で自分軸ファインダーを始めてください
```

**2. Claude Code に入れる**
```
/plugin marketplace add s4qr-tech/no-dakyou-job
/plugin install no-dakyou-job@no-dakyou-job
```

**3. ZIPで入れる（claude.ai のスキルとして登録）**
下の「導入手順」を参照。

## 導入手順

### Claude に入れる
1. このリポジトリを ZIP で取得する（またはリリースの配布用 ZIP を使う）。ZIP の最上位に `no-dakyou-job/` フォルダ（中に SKILL.md）があること。
2. Claude の「Customize > Skills」から、ZIP をアップロードする。（画面の名称は変わることがあります。Claude のヘルプで最新の手順を確認してください）
3. スキル一覧で `no-dakyou-job` をオンにする。
4. チャットで `/no-dakyou-job` と入力して始める。

### Claude Code で使う場合

```
/plugin marketplace add s4qr-tech/no-dakyou-job
/plugin install no-dakyou-job@no-dakyou-job
```
スキルの本体は `skills/no-dakyou-job/` にあります。手動で入れる場合は、このフォルダを `~/.claude/skills/` に置いてください。

### claude.ai のチャットで使う場合
URL指定では導入できません。配布用ZIP（Releases）をダウンロードし、「Customize > Skills」からアップロードしてください。

## 使い方
- `/no-dakyou-job` と入力して開始。言語モード（日本語／英語／両方）を選ぶと、ステップ0から1つずつ進みます。
- 1回で終わらせなくて構いません。途中で止めて、前回の成果物を貼り付ければ、続きから再開できます。
- 話したくないことは、いつでもスキップできます。
- ステップ5〜6の後に出力される `jiku-profile.md` を保存して、`/jobh-jp` に渡すと、企業研究から面接準備まで同じ自分軸で進められます。
- 選考のあとは、「A社の一次面接が終わった」などと話しかけると、軸に照らした振り返りができます。

## /jobh-jp との連携
- `jobh-jp` が使える環境では、no-dakyou-job から呼び出して、自分軸を引き継げます。
- 引き継ぐ観点：募集評価に「自分軸との一致」を追加／設問回答の志望動機・将来像を軸に紐づけ／最終チェックに軸との一貫性を追加／面接準備に軸の一貫性を問う質問を追加。
- `jobh-jp` が使えない場合は、`jiku-profile.md` を保存して、応募時に貼り付けてください。
- `jobh-jp` は本リポジトリに含まれていません。別途導入してください。

## リマインド（任意）
本スキルは、定期リマインドを組み込んでいません。選考中に定期的に振り返りたい場合は、各自の環境で設定してください（例：毎週日曜の朝に「今週の選考を自分軸に照らして振り返る」というタスクを作る）。設定できる機能は、プランや環境によって異なります。
